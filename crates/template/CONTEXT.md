# Template Context

Handles the loading, evaluation, and execution of dynamic blueprints to generate content artifacts in the vault.

## Language

**Template**:
A text document containing frontmatter and embedded evaluation logic used as a blueprint to generate new notes.
_Avoid_: Blueprint, snippet, draft

**Render**:
The process of evaluating a template's embedded logic against provided data variables to produce the final text output.
_Avoid_: Compile, execute, process

**Artifact**:
The final, rendered output generated from a template, typically written to the vault as a new file.
_Avoid_: Output file, generated note, result

**Dry Run**:
An evaluation mode that renders a template and surfaces the artifact's content without writing anything to the filesystem.
_Avoid_: Preview, simulation, test render

**Extension**:
A first-party capability injected into the template engine to provide domain-specific features (like date formatting or path manipulation) directly to template authors.
_Avoid_: Plugin, helper, custom script, user macro

**Pure Extension**:
An extension that transforms or generates data entirely in memory without interacting with external state or causing side effects.
_Avoid_: Stateless extension, pure function

**Effectful Extension**:
An extension that performs I/O or side effects during rendering, such as reading external files or defining where the artifact should be saved.
_Avoid_: Stateful extension, I/O extension, impure extension

**Side Channel Command**:
An instruction generated by an effectful extension mid-render (such as setting a dynamic output path) that the system extracts and executes after rendering completes.
_Avoid_: Post-render hook, state temp, out-of-band data
