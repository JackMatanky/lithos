### Architecture Patterns

**Before (Deprecated):**
```go
type FileMetadata struct {
    Path     string      // Absolute path
    Basename string      // Cached computation
    Folder   string      // Cached computation
    Ext      string      // Cached computation
    ModTime  time.Time   // Duplicates fs.FileInfo
    Size     int64       // Duplicates fs.FileInfo
    MimeType string      // Cached computation
}

type VaultFile struct {
    FileMetadata         // Embedding deprecated struct
    Content      []byte
}
```

**After (Redesigned):**
```go
type VaultFile struct {
    Path    string      // Vault-relative: "notes/meeting.md" (forward slashes)
    Info    fs.FileInfo // Delegates to stdlib (ModTime, Size, Mode, IsDir)
    Content []byte      // Raw file content
}

// Computed methods (no caching, compute on-demand)
func (vf VaultFile) Basename() string {
    base := filepath.Base(vf.Path)
    return strings.TrimSuffix(base, filepath.Ext(base))
}

func (vf VaultFile) Folder() string {
    return filepath.Dir(vf.Path)
}

func (vf VaultFile) Ext() string {
    return filepath.Ext(vf.Path)
}

func (vf VaultFile) ModifiedAt() time.Time {
    return vf.Info.ModTime()  // Delegate to fs.FileInfo
}

func (vf VaultFile) Size() int64 {
    return vf.Info.Size()  // Delegate to fs.FileInfo
}

// Path normalization helpers
func NormalizePath(absPath, vaultRoot string) (string, error) {
    relPath, err := filepath.Rel(vaultRoot, absPath)
    if err != nil {
        return "", err
    }
    return filepath.ToSlash(relPath), nil  // "notes/meeting.md"
}

func (vf VaultFile) AbsolutePath(vaultRoot string) string {
    return filepath.Join(vaultRoot, filepath.FromSlash(vf.Path))
}

// Constructor
func NewVaultFile(absPath, vaultRoot string, info fs.FileInfo, content []byte) (VaultFile, error) {
    relPath, err := NormalizePath(absPath, vaultRoot)
    if err != nil {
        return VaultFile{}, err
    }

    return VaultFile{
        Path:    relPath,
        Info:    info,
        Content: content,
    }, nil
}
```

**Benefits:**
- ✅ No duplication: ModTime, Size, Mode, IsDir from fs.FileInfo
- ✅ Computed methods: No memory overhead for cached fields
- ✅ Vault-relative paths: "notes/meeting.md" instead of "/vault/notes/meeting.md"
- ✅ Cross-platform: Forward slashes in storage, OS-specific at I/O boundaries
- ✅ Naming consistency: ModifiedAt() aligns with IndexedAt pattern

### Cache Staleness Pattern

**Cache Adapter IndexedAt Tracking:**
```go
// Cache adapter writes
type CachedNote struct {
    Path       string    // From note.Path()
    ModifiedAt time.Time // From note.ModifiedAt() - file modification time
    IndexedAt  time.Time // time.Now() when cached
    // ... other fields
}

// Staleness detection
if file.ModifiedAt().After(cached.IndexedAt) {
    // File changed after indexing → cache stale, reindex needed
}
```
