# Story 3.17: VaultFile DTO Redesign with Layered Architecture

## Status: Draft

## Story

**As a** system architect,
**I want** VaultFile DTO redesigned using fs.FileInfo delegation, vault-relative paths, and content separation,
**so that** we eliminate duplication, enable cross-platform compatibility, and optimize memory usage.

## Acceptance Criteria

**Layer 1 - Base DTO** (AI-1.1 + AI-1.2):
1. ✅ Refactor `VaultFile` struct:
   ```go
   type VaultFile struct {
       Path    string      // Vault-relative: "notes/meeting.md"
       Info    fs.FileInfo // Delegate to stdlib (ModifiedAt, Size, Mode, IsDir)
       Content []byte      // Loaded on-demand
   }
   ```
2. ✅ Add computed methods: `Basename()`, `Folder()`, `Ext()`, `ModifiedAt()`, `Size()`
3. ✅ Remove duplicated fields: Basename, Folder, Ext, ModifiedAt, Size, MimeType
4. ✅ Path normalization helper: `NormalizePath(absPath, vaultRoot string) (string, error)` using filepath.ToSlash
5. ✅ Helper: `AbsolutePath(vaultRoot string) string` for I/O operations

**Layer 2 - Content Separation** (AI-2.2):
6. ✅ Create `VaultFileMeta` struct (metadata only - NO Content):
   ```go
   type VaultFileMeta struct {
       Path string
       Info fs.FileInfo
   }
   ```
7. ✅ Create `VaultFileWithContent` struct (metadata + content):
   ```go
   type VaultFileWithContent struct {
       VaultFileMeta
       Content []byte
   }
   ```
8. ✅ Update VaultScannerPort methods:
   - `ScanAll(ctx) ([]VaultFileMeta, error)` - fast metadata scan
   - `ScanWithContent(ctx) ([]VaultFileWithContent, error)` - when content needed

**Cross-Platform Paths** (Gap 7.1):
9. ✅ All path storage uses forward slashes (filepath.ToSlash)
10. ✅ I/O operations convert to OS-specific paths (filepath.FromSlash)

**Cache Staleness Detection**:
11. ✅ Note methods for cache writes:
    - `note.ModifiedAt()` returns file modification time (from VaultFile.Info)
    - Cache adapters add `IndexTime` when writing (time.Now())
12. ✅ Staleness detection logic:
    - If `fileModifiedAt.After(cachedIndexTime)` → cache is stale, reindex

**Testing**:
13. ✅ Unit tests: fs.FileInfo delegation, computed methods, path normalization
14. ✅ Cross-platform tests: Windows/Linux/Mac path compatibility
15. ✅ Memory tests: VaultFileMeta vs VaultFileWithContent memory usage

### Architecture Patterns

**Layered DTO Design:**
- Layer 1 (Base): VaultFile with fs.FileInfo delegation - eliminates duplication
- Layer 2 (Content Separation): VaultFileMeta vs VaultFileWithContent - memory optimization
- Storage uses Note/VaultFile methods directly (no storage-specific DTOs needed)

**Vault-Relative Paths:**
All internal paths use vault-relative format ("notes/meeting.md") with forward slashes for consistency. Conversion to absolute OS-specific paths happens only at I/O boundaries (adapter layer).

**fs.FileInfo Delegation:**
VaultFile embeds fs.FileInfo to delegate ModifiedAt, Size, Mode, IsDir directly to stdlib. Computed methods (Basename, Folder, Ext) cache results to avoid repeated string operations.

**Content Separation Strategy:**
- VaultFileMeta: Fast metadata-only scans for file discovery
- VaultFileWithContent: Full content loading when parsing needed
- Memory savings: Skip loading binary files, large files during metadata scans

**Cache Adapter Pattern (No Storage DTOs):**
Cache adapters (BoltDB, SQLite) use Note and VaultFile methods directly without intermediate storage-specific DTOs:
- **For writes:** Cache adapters call `note.Path()`, `note.ModifiedAt()`, `note.Frontmatter()` to extract data for storage
- **IndexTime tracking:** Cache adapter adds `IndexTime = time.Now()` at write time alongside file's `ModifiedAt`
- **Staleness detection:** Query cached `IndexTime` vs current `file.ModifiedAt()` to detect stale entries
- **No conversion layer:** Eliminates BoltDBMetadata/SQLiteMetadata DTOs - use domain methods directly

Example BoltDB write pattern:
```go
func (w *BoltDBWriter) Write(ctx context.Context, note domain.Note) error {
    indexTime := time.Now()
    data := CachedNote{
        Path:       note.Path(),
        ModifiedAt: note.ModifiedAt(),  // From file
        IndexTime:  indexTime,           // When cached
        // ... other fields from note methods
    }
    // Store data in BoltDB
}
```
