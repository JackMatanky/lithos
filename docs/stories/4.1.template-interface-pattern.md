### Architecture Patterns

**Hexagonal Architecture (Ports & Adapters):**
Template is a domain interface, GoTemplate is the adapter:
- **Domain Layer:** Template interface (no stdlib dependencies)
- **Adapter Layer:** GoTemplate wraps *template.Template
- **Application Layer:** Depends only on Template interface

**Dependency Inversion:**
High-level services depend on Template abstraction, not concrete GoTemplate:
- **Testability:** Mock Template for pure domain tests
- **Flexibility:** Swap template engines without changing domain
- **Domain Purity:** No *template.Template in domain/app layers

**Wrapper Pattern:**
GoTemplate encapsulates *template.Template complexity:
- Buffer management hidden from consumers
- Error handling simplified
- Type-safe TemplateID

### Template Composition Support

**Shared FuncMap Pattern:**
```go
type GoTemplateAdapter struct {
    templates map[TemplateID]*template.Template
    funcMap   template.FuncMap
}

func NewGoTemplateAdapter(templateDir string, funcMap template.FuncMap) (*GoTemplateAdapter, error) {
    adapter := &GoTemplateAdapter{
        templates: make(map[TemplateID]*template.Template),
        funcMap:   funcMap,
    }

    // Parse all templates with shared function map
    baseTmpl := template.New("base").Funcs(funcMap)
    tmpl, err := baseTmpl.ParseGlob(filepath.Join(templateDir, "*.tmpl"))
    if err != nil {
        return nil, err
    }

    // Wrap each parsed template in GoTemplate
    for _, t := range tmpl.Templates() {
        id := TemplateID(t.Name())
        adapter.templates[id] = t
    }

    return adapter, nil
}
```

### Risks and Mitigations

**MEDIUM RISK: Template composition may break with wrapper**
- **Impact:** Templates calling other templates may not work
- **Mitigation:** Parse all templates together with shared FuncMap; test composition
- **Validation:** Integration tests with template composition ({{template "base" .}})

**LOW RISK: Performance overhead from wrapping**
- **Impact:** Buffer allocation on every Execute()
- **Mitigation:** Benchmark to ensure < 1ms overhead; acceptable for domain purity
- **Validation:** Performance tests comparing wrapped vs unwrapped execution
