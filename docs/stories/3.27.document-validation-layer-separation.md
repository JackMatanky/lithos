### Architecture Patterns

**Hexagonal Architecture (Ports & Adapters):**
Validation layer separation enforces hexagonal architecture boundaries:
- **Adapter Layer:** Syntactic validation (YAML parsing, file format)
- **Domain Layer:** Semantic validation (business rules, schema compliance)

**Naming Convention Pattern:**
Clear naming distinguishes validation types:
```go
// Adapter Layer (syntactic)
func (p *GoldmarkParser) ValidateSyntax(content []byte) error
func (p *GoldmarkParser) IsValidSyntax(content []byte) bool

// Domain Layer (semantic)
func (s *FrontmatterService) IsSchemaCompliant(ctx context.Context, fm Frontmatter) error
func (v *SchemaValidator) Validate(ctx context.Context, schema Schema) error
```

**Separation of Concerns:**
Each layer has distinct validation responsibility:
- **Syntactic:** Can we parse this? Is format correct?
- **Semantic:** Does this meet business rules? Is schema compliant?
