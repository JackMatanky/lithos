## Agent Brief

> *This was generated by AI during triage.*

### Summary

This is a **CRITICAL** refactor that unifies filesystem entry handling. We are moving from `FileEntry` (a struct capturing only file data) to `FsEntry` (an enum capturing both Files and Directories).

**Key Refactor Rules:**
- Consumers that previously only worked with files must now explicitly handle or filter for `FsEntry::File`.
- To minimize breakage, we will add ergonomic compatibility methods to `FsEntry` (e.g., `metadata()`, `filename()`).
- Data access changes from direct field access (`entry.path`) to method calls (`entry.path()`).

### Impact Analysis

**GitNexus Analysis:**
- **CRITICAL Risk**: `FileEntry` is a backbone type for discovery.
- **Affected Processes**:
  - `config/builder.rs`: `load()` flow.
  - `schema/discovery.rs`: `run()` and `scan_filesystem()` flows.
  - `fs/reader.rs`: `list_entries()` and filtering logic.
- Grep shows **104 usage sites**.
- Module impact: **Fs** (direct), **Config** (direct), **Schema** (indirect).

### Phased Migration Checklist

#### Phase 1: Infrastructure Enhancement (`fs/entry.rs`)
- [ ] Add `metadata(&self) -> FsMetadata` to `FsEntry`.
- [ ] Add `filename(&self) -> FileName` to `FsEntry` (extracting from underlying path).
- [ ] Ensure `FsFile` and `FsDir` provide consistent accessors.

#### Phase 2: `DirScanner` & `FsReader` Update
- [ ] **`scanner.rs`**: Change `DirScanner::entries` to return `Vec<FsEntry>`. (Note: `entries_typed` already exists, consider unification).
- [ ] **`reader.rs`**: Update `list_entries` and related filtering methods.
- [ ] **Tests**: Update `fs` module tests to handle the new enum return types.

#### Phase 3: Consumer Discovery Migration
- [ ] **`schema/discovery.rs`**: Update `SchemaDiscovery` and `PropertyBankDiscovery` structs. Filter for files where directories are invalid.
- [ ] **`config/discovery.rs`**: Update `DiscoveryEngine` and related result types.
- [ ] **`vault/`**: Update any processor or storage logic that consumes entries.

#### Phase 4: Cleanup
- [ ] **`file.rs`**: Delete the `FileEntry` struct.
- [ ] **`mod.rs`**: Remove `FileEntry` re-export.
- [ ] **Tests**: Final pass on all integration tests.
