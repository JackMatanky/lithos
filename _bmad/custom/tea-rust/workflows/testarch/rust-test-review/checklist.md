# Rust Test Review Checklist

- [ ] Target path provided (file/module)
- [ ] All public components validated
- [ ] Scope expansion documented when dependencies require it
- [ ] GWT comments present in tests
- [ ] Doc comment usage aligns with test type
- [ ] Error paths covered
- [ ] Flaky tests addressed
- [ ] Anti-patterns removed
- [ ] Rust style and linting standards adhered to (clippy clean or `#[expect]` justified)
- [ ] Fixes applied (not only suggestions)
