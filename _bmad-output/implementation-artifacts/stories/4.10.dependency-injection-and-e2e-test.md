## Implementation Details

### Dependency Injection Architecture

**DI Container Structure:**
```go
// main.go - Application wiring
container := di.NewContainer()

// Schema-driven components
container.Register(&template.TemplateEngine{})
container.Register(&query.QueryService{})
container.Register(&frontmatter.FrontmatterService{})
container.Register(&schema.SchemaEngine{})

// Event infrastructure
container.Register(&events.EventBus{})
container.Register(&publisher.EventPublisher{})

// Wire dependencies
templateEngine := container.Resolve("template.TemplateEngine")
templateEngine.SetQueryService(container.Resolve("query.QueryService"))
// ... additional wiring
```

### End-to-End Test Structure

**Test Organization:**
```
tests/
├── e2e/
│   ├── schema_driven_lookups_test.go
│   ├── fixtures/
│   │   ├── test_schemas.json
│   │   └── test_templates/
│   └── helpers/
│       ├── test_app.go
│       └── test_data.go
```

**Test Example:**
```go
func TestSchemaDrivenLookupWorkflow(t *testing.T) {
    // Setup full application context
    app := testhelpers.NewTestApp()
    defer app.Cleanup()

    // Create test schema and data
    schemaID := app.CreateTestSchema(fixtures.TestSchema)
    templateID := app.CreateTestTemplate(fixtures.TemplateWithLookups)

    // Execute complete workflow
    note, err := app.ExecuteNewNote(templateID)
    require.NoError(t, err)

    // Validate results
    assert.NotNil(t, note)
    assert.True(t, app.ValidateSchemaCompliance(note, schemaID))

    // Test query functionality
    results := app.ExecuteQuery(fmt.Sprintf("schema:%s", schemaID))
    assert.Contains(t, results, note)
}
```
