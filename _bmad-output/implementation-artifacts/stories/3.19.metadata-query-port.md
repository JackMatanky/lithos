# Story 3.19: MetadataQueryPort - Index-Based Query Interface

## Status: Done

## Story

**As a** system architect,
**I want** a dedicated MetadataQueryPort interface for index-based note queries (BasenameQuery, AliasQuery, FileClassQuery),
**so that** we enable efficient metadata lookups with proper port/adapter separation and support the hybrid storage architecture.

## Acceptance Criteria

**New Port Definition**:
1. ✅ Create `/internal/ports/spi/metadata_query.go`:
   ```go
   type MetadataQueryPort interface {
       // BasenameQuery finds notes by filename without extension
       // Returns all notes with matching basename (handles duplicates)
       BasenameQuery(ctx context.Context, basename string) ([]domain.Note, error)

       // AliasQuery finds notes by frontmatter alias values
       // Returns all notes containing the alias in aliases array
       AliasQuery(ctx context.Context, alias string) ([]domain.Note, error)

       // FileClassQuery finds notes by schema fileClass value
       // Returns all notes with matching fileClass frontmatter field
       FileClassQuery(ctx context.Context, fileClass string) ([]domain.Note, error)

       // PathQuery resolves notes by full path, basename, or folder scope.
       PathQuery(ctx context.Context, opts PathQueryOptions) ([]domain.Note, error)
   }

   type PathQueryScope string
   const (
       PathQueryScopeFull    PathQueryScope = "full"
       PathQueryScopeBasename PathQueryScope = "basename"
       PathQueryScopeFolder  PathQueryScope = "folder"
   )

   type PathQueryOptions struct {
       Scope PathQueryScope
       Value string
   }
   ```

### Architecture Patterns

**Port/Adapter Pattern:**
- MetadataQueryPort (SPI): Contract defined by domain query needs
- Future adapters: BoltDBReaderAdapter, SQLiteReaderAdapter will implement this interface
- Clear separation: Port defines WHAT, adapters define HOW

**Interface Segregation:**
MetadataQueryPort focuses specifically on index-based metadata queries:
- **NOT included**: Full-text search (different interface)
- **NOT included**: Complex frontmatter queries (SQLiteQueryPort)
- **Included**: Fast index lookups by basename, alias, fileClass

**Complementary Interfaces:**
- **CacheReaderPort**: Basic cache operations (Read by path, List all)
- **MetadataQueryPort**: Index-based queries (BasenameQuery, AliasQuery, FileClassQuery)
- **QueryService**: Orchestrates queries across multiple ports

**Query Routing Strategy:**
```go
// QueryService routes queries to appropriate ports
func (s *QueryService) FindBasenameQuery(basename string) ([]Note, error) {
    // Route to MetadataQueryPort for fast index lookup
    return s.metadataQuery.BasenameQuery(ctx, basename)
}

func (s *QueryService) ComplexFrontmatterQuery(criteria map[string]any) ([]Note, error) {
    // Route to SQLiteQueryPort for complex queries (future story)
    return s.sqliteQuery.QueryFrontmatter(ctx, criteria)
}
```
