## Acceptance Criteria

1. Note aggregate includes: Note, Frontmatter, Links, Embeds, Tags, Headings, Tasks, and Sections.
2. Frontmatter is a subentity of Note.
3. Internal consistency validation occurs on creation.
4. Support for vault-relative paths and wiki-link resolution.
5. Note IDs use **UUID v7** for strict chronological ordering and stability (R-002).
6. All file paths (Note path, Embed paths) are validated against **Path Traversal** (R-004).
7. Domain events (NoteCreated, NoteFrontmatterValidated) and CQRS ports (NoteCommand, NoteQuery).
